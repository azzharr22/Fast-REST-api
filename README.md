Hello this is a student management project for a school.

    This API has currently 3 endpoints:
        a) GET method to get the particular student by his PRIMARY KEY in database.
        b) POST method to create a new studend in the database.
        c) GET method to get the list of all the students.
    

    All the data will be recieved in JSON format.

That's all for this project but in future I am hoping to extend on this project and create a new one with many other endpoints like teachers, execs etc.
